把讲义、测验、手稿的 PDF 放进这个文件夹，主页「资料」页会自动列出，不用改代码。

命名建议（前缀决定归到哪一组）：
  handout-01-xxx.pdf   →  讲义
  quiz-01-xxx.pdf      →  测验
  notes-01-xxx.pdf     →  手稿

前缀可用：handout / quiz / test / notes / draft，不匹配的会归到「其他」。

序号用两位数（01、02…），列表会按数字顺序排。

文件名可以带中文（如 01-化学基础.pdf），页面上显示正常；
只是复制链接时会变成一长串编码，所以对外转发链接时注意一下。

不需要的文件（如本说明）不会出现在列表里，页面只读 .pdf。
